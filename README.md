# AutoCity — ゲーム設計書

## 1. ゲーム概要

10×10 グリッド上にテトロミノ型の建物を配置し、50 年間の自動シミュレーションで都市を成長させるパズルゲーム。

- **目的**: Year 50 終了時の都市スコア最大化
- **対戦要素**: なし（ソロプレイ）
- **シード制**: シードごとに建物セット（ポート配置）が固定され、リプレイ・比較が可能

## 2. 資源タイプ

SimCity の RCI モデルに基づく 3 種類の資源。

| 資源 | 記号 | 供給元 |
|------|------|--------|
| 人口 (Population) | Pop | R（住宅） |
| サービス (Service) | Srv | C（商業） |
| 商品 (Goods) | Gds | I（工業） |

## 3. 建物タイプ

全建物は **テトロミノ（4 マス）** で構成される。各建物には **3 つのポート** が外周辺からシードによりランダムに配置される。

### 3.1 R — 住宅 (Residential)

**形状: O 型テトロミノ（2×2）**

```
##
##
```

- **供給**: Population（人口）
- **需要**: Service（サービス）
- **回転**: 4 回転すべて同一形状
- **外周辺数**: 8

### 3.2 C — 商業 (Commercial)

**形状: S 型テトロミノ**

```
回転 0°:     回転 90°:
 ##           #
##            ##
               #
```

- **供給**: Service（サービス）
- **需要**: Population（人口）**かつ** Goods（商品）— 両方必要
- **回転**: 2 パターン（0°/180° 同一、90°/270° 同一）
- **外周辺数**: 10

### 3.3 I — 工業 (Industrial)

**形状: I 型テトロミノ（4×1）**

```
回転 0°:     回転 90°:
####          #
              #
              #
              #
```

- **供給**: Goods（商品）
- **需要**: Population（人口）
- **回転**: 2 パターン（0°/180° 同一、90°/270° 同一）
- **外周辺数**: 10

### 3.4 資源依存グラフ

```
R (住宅) ──Pop──▶ C (商業) ──Srv──▶ R (住宅)
    ▲                │
    │               Pop
   Pop               │
    │                ▼
I (工業) ──Gds──▶ C (商業)
```

- R → Population → C, I
- C → Service → R
- I → Goods → C

## 5. 配置ルール

- **回転**: 90° 単位。ミラー（反転）なし
- **隣接**: 建物同士の隣接は可能
- **重複**: 不可（同じマスに複数の建物を置けない）
- **同一建物の複数配置**: 可能（同じ建物構成を何度でも使える）
- **配置数制限**: なし（グリッドが許す限り自由）
- **選択順**: 自由。シードで決まる全建物が最初から提示される
- **削除**: 建設フェイズ中は自由に削除可能
- **Undo**: 実装予定（モック段階では不要）
- **時間制限**: なし

## 6. ポートと道路ネットワーク

### 6.1 ポート

- 各建物は **3 つのポート** を持つ
- ポートは建物の **外周辺** の中からシードによりランダムに選ばれる
- ポートのある辺が道路の端点となる

### 6.2 接続条件

2 つの建物が **道路で接続** されるには：

1. 建物 A のセルと建物 B のセルがグリッド上で隣接している（共有辺を持つ）
2. その共有辺の **両側にポートが存在** する

```
例: 接続される
  A のセル (2,3) の右辺にポート
  B のセル (3,3) の左辺にポート
  → 共有辺でポート同士が向き合う → 接続

例: 接続されない
  A のセル (2,3) の右辺にポート
  B のセル (3,3) の左辺にポートなし
  → ポートが片側のみ → 非接続
```

### 6.3 ネットワーク

- **空きマスでは道路は延長されない** — 建物のポート同士が直接隣接していなければ接続不可
- 複数の建物がポート接続で連鎖すると **道路ネットワーク** が形成される
- 分岐（T 字・十字）がある場合は **最短経路** で距離を計算

### 6.4 ポート配置例

O 型テトロミノの外周辺（8 辺）:

```
 ←T1→←T2→
L1 ## R1
L2 ## R2
 ←B1→←B2→
```

8 辺から 3 つを選択。例えば T1, R2, B1 にポートが配置される場合：

```
  ↑
  ##→
  ##
  ↓
```

## 7. 供給システム

### 7.1 距離

建物間の距離は、道路ネットワーク上の **最短経路のホップ数** で定義する。

- 直接ポート接続された 2 建物: 距離 = 1
- A—B—C と接続: A から C の距離 = 2
- 道路で接続されていない建物間: 距離 = ∞（供給不可）

### 7.2 距離減衰

```
weight(d) = max(0, 1 − d × decay_rate)
```

- **decay_rate = 0.1**（初期値）
- 距離 1: weight = 0.9
- 距離 5: weight = 0.5
- 距離 10: weight = 0.0
- **最大距離制限なし** — 減衰で自然にゼロ収束

### 7.3 供給分配

供給元 S から、その資源を需要するすべての建物 D₁, D₂, ..., Dₙ への分配：

```
Dᵢ への供給量 = S.supply × weight(dᵢ) / Σⱼ weight(dⱼ)
```

ここで `dᵢ` = S から Dᵢ への最短経路距離。

**例**: S（供給量 10）から D₁（距離 1）と D₂（距離 3）がある場合：

```
weight(D₁) = max(0, 1 − 1 × 0.1) = 0.9
weight(D₂) = max(0, 1 − 3 × 0.1) = 0.7

D₁ への供給 = 10 × 0.9 / (0.9 + 0.7) = 10 × 0.5625 = 5.625
D₂ への供給 = 10 × 0.7 / (0.9 + 0.7) = 10 × 0.4375 = 4.375
```

> 注: weight の合計がゼロ（需要先がすべて到達不能）の場合、供給は消滅する。

## 8. レベルアップシステム

### 8.1 基本ルール

- **初期レベル**: 1（配置直後からレベル 1 の供給・需要が発生）
- **最大レベル**: 10
- **レベルアップ条件**: 蓄積された資源量がそのレベルの需要閾値に達する
- **複数需要**: C のように複数資源を需要する場合、**すべて** の閾値を同時に満たす必要がある
- **複数段レベルアップ**: 1 年のレベルアップフェイズで何段階でも上がれる
- **余剰持ち越し**: レベルアップ時に閾値分を消費し、残りは次のレベルの蓄積に持ち越す

### 8.2 レベルアップ処理

```
for each building:
    while building.level < MAX_LEVEL:
        threshold = base_demand × building.level
        if (全需要資源の蓄積 ≧ threshold):
            各需要資源の蓄積 -= threshold
            building.level += 1
        else:
            break
```

### 8.3 レベルアップ効果の反映タイミング

レベルアップは **レベルアップフェイズ** で処理され、その効果（供給量増加）は **翌年の供給フェイズ** から反映される。

## 9. ゲーム進行

### 9.1 フェイズ構成

```
┌─────────────────────────────────────────┐
│          建設フェイズ（手動）              │
│  プレイヤーがグリッドに建物を配置         │
│  制限時間なし・自由に配置/削除/回転        │
│  完了ボタンでシミュレーション開始          │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│      Year 1 〜 Year 50 自動進行          │
│                                         │
│  各年の処理順:                            │
│    1. 供給フェイズ                        │
│       - 各建物が現在レベルの供給量を生産    │
│       - 道路ネットワーク経由で需要先に分配  │
│       - 受け取った資源は蓄積に加算         │
│    2. レベルアップフェイズ                 │
│       - 蓄積量が閾値に達した建物がレベルアップ │
│       - 複数段昇格可能                    │
│    3. Year 加算                          │
└─────────────────────────────────────────┘
```

### 9.2 50 年シミュレーション例

初期配置: R₁ — C₁ — I₁（すべて隣接ポート接続、距離 1）

```
Year 1:
  供給: R₁(Lv1)→2 Pop, C₁(Lv1)→2 Srv, I₁(Lv1)→2 Gds
  分配:
    Pop → C₁: 2×0.9/(0.9+0.9)=1.0, I₁: 1.0
    Srv → R₁: 2×0.9/0.9=2.0
    Gds → C₁: 2×0.9/0.9=2.0
  蓄積: R₁[Srv:2.0] C₁[Pop:1.0,Gds:2.0] I₁[Pop:1.0]
  レベルアップ: なし（全建物閾値3未達）

Year 2:
  供給: 同上（レベル変化なし）
  蓄積: R₁[Srv:4.0] C₁[Pop:2.0,Gds:4.0] I₁[Pop:2.0]
  レベルアップ: R₁ Srv 4.0≧3 → Lv2（残余 1.0）

Year 3:
  供給: R₁(Lv2)→4 Pop, C₁(Lv1)→2 Srv, I₁(Lv1)→2 Gds
  分配:
    Pop → C₁: 2.0, I₁: 2.0
    Srv → R₁: 2.0
    Gds → C₁: 2.0
  蓄積: R₁[Srv:3.0] C₁[Pop:4.0,Gds:6.0] I₁[Pop:4.0]
  レベルアップ:
    R₁ Srv 3.0≧6? No
    C₁ Pop 4.0≧3 AND Gds 6.0≧3 → Lv2（残余 Pop:1.0, Gds:3.0）
      Pop 1.0≧6? No → 停止
    I₁ Pop 4.0≧3 → Lv2（残余 1.0）
```

## 10. スコアリング

### 10.1 計算式

```
Score = log₁₀(累積供給総量) + log₁₀(最終レベル合計)
```

- **累積供給総量**: 全建物の 50 年間の供給量合計（実際に生産した量。消費されたかは問わない）
- **最終レベル合計**: Year 50 終了時の全建物のレベル合計

### 10.2 例

15 棟配置、平均レベル 5、累積供給 5000 の場合：

```
Score = log₁₀(5000) + log₁₀(75)
      ≈ 3.70 + 1.88
      = 5.58
```

> **+α**: 将来的にネットワーク接続ボーナスや建物組み合わせボーナスなどの追加スコア要素を検討。現時点では未定義。

## 11. シードシステム

- シード値（整数）を入力すると、建物セットが決定論的に生成される
- **シードが決定するもの**: 各建物タイプの **ポート位置**（外周辺 3 箇所の選択）
- 同一シードでは常に同じ建物セットが提供される
- 全建物が最初から提示され、プレイヤーは自由に選択・複数回配置可能

## 13. 建物データ構造

```
Building {
    type: R | C | I
    shape: Cell[]              // 占有マス（相対座標）
    ports: Port[]              // ポート（辺の位置）
    supply_resource: Pop | Srv | Gds
    supply_per_level: number   // base_supply（レベル×この値=毎年の供給量）
    demand_resources: { resource: Pop|Srv|Gds, base_demand: number }[]
    level: number              // 現在レベル（1〜10）
    accumulated: { [resource]: number }  // 資源蓄積量
}

Cell {
    dx: number    // 建物原点からの相対 X
    dy: number    // 建物原点からの相対 Y
}

Port {
    cell: Cell       // ポートが属するセル
    direction: N|S|E|W  // 辺の方向
}
```

## 15. 用語集

| 用語 | 説明 |
|------|------|
| グリッド | 10×10 の正方形マス目。建物を配置する場 |
| テトロミノ | 4 マスで構成される建物の形状 |
| ポート | 建物の外周辺に配置される接続点。道路の端点 |
| 道路 | 隣接するポート同士で形成される接続 |
| ネットワーク | 道路で接続された建物群のグラフ構造 |
| ホップ | ネットワーク上の建物間接続 1 つ分の距離 |
| シード | 建物セットを決定論的に生成する整数値 |
| 供給 | 建物が毎年生産する資源量 |
| 需要閾値 | レベルアップに必要な蓄積資源量 |
| 蓄積 | 建物が受け取った資源の累計（レベルアップで消費） |
| decay_rate | 距離減衰率。初期値 0.1 |
